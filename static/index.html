For the Davis dataset, scores are reported as pKd (higher values indicate tighter binding; scores ≥ 7.0 typically indicate active binding, corresponding to Kd ≤ 100 nM). For KIBA, scores reflect integrated bioactivity (values ≥ 12.1 generally indicate strong interaction).
Predictions are generated by a dual 1D Convolutional Neural Network (DeepDTA) trained on kinase–inhibitor pairs. While useful for rapid virtual screening, computational scores should be validated with experimental assays before downstream use.
No active sequence warnings. Inputs longer than the model's maximum window (85 characters for Davis SMILES, 100 for KIBA SMILES, and 1,200/1,000 residues for proteins) are automatically truncated.
